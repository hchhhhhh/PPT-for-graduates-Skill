# 毕业答辩 PPT 修改指南

## 核心总纲领

答辩 PPT 不是论文的复制粘贴，而是要构建一条由**研究意义—核心难题—研究工作—研究结果**组成的闭环叙事。讲完整一条研究故事线，让每一部分前后关联；结果要回应开篇提出的难题与研究意义，形成逻辑闭环。

## 一、顶层逻辑框架：一线式闭环叙事

整套 PPT 的所有页面都要服务于这条逻辑链，避免各部分互相脱节：

1. **意义（为什么做）**：讲清领域价值与现实需求，说明研究值得投入，并引出现存痛点。
2. **难题（问题在哪）**：从研究意义过渡，明确当前研究尚未解决的短板和核心瓶颈。难题要具体，不能泛泛而谈；后续工作都应围绕这些难题展开。
3. **工作（我做了什么）**：介绍研究内容、方法和技术路线。每项工作都要对应前面提出的某个难题，回答“为了解决这个难题，我采取了什么方案”，避免工作与问题脱节。
4. **结果（效果如何）**：展示实验、仿真或数据分析结果，证明前面提出的难题得到了改善或解决，并反过来印证研究意义，完成闭环。

### 闭环自检

听完汇报后，评委应能清晰复述：

> 因为有 **XX 意义**，存在 **XX 难题**；我做了 **XX 工作**，得到 **XX 结果**，解决了 **XX 难题**，实现了 **XX 价值**。

**常见反面问题：**背景讲了很多但难题模糊；后续工作和难题无关；结果只罗列数据，却没有回应当初要解决的问题。

## 二、内容取舍：压缩、保留与删除

1. **不要把论文章节直接搬到 PPT。**评委手上有论文，PPT 应展示论证链条，而不是复制大段文字。
2. **大幅压缩文献综述。**不按时间线罗列大量前人工作，只挑与研究难题直接相关的文献，用来说明“前人还没有解决什么”，服务于研究缺口的引出。通常 1–2 页即可。
3. **删减教科书级基础科普。**面向同行评委，不必讲解领域基础概念，避免浪费汇报时间。
4. **保留核心内容。**重点展示研究难题、技术方案、核心对比实验结果和创新点。次要实验、细碎推导、大量原始数据放入备份 PPT，答辩时不主动讲，评委提问时再调取。
5. **创新点不超过 3 条。**每条都要对应“前人局限（难题）→我的改进（工作）→带来的提升（结果）”，避免空洞口号。

**删页自检：**如果删掉这一页，会改变评委对你研究工作的判断吗？如果不会，就删掉。

## 三、页面布局与视觉排版

1. **一页一论点。**每张幻灯片只讲一个核心观点。标题直接写本页核心结论，而不是“2.3 实验介绍”这样的章节标题。
2. **图优于表，表优于大段文字。**优先使用流程图、框图和对比曲线图；把长段文字拆成简短要点，避免页面文字过满。
3. **技术路线图是叙事骨架。**路线图不能只是流程图，还要体现针对哪个难题、采用什么模块、输出什么结果，串联“难题—工作—结果”。
4. **规范图表。**结果图要突出对比，并高亮改善或提升的关键信息；图表标注完整。去掉多余装饰和动画。动画仅用于分步展示流程，避免花哨效果及投影设备兼容问题。
5. **字号清晰，留白充分。**保证后排观众也能看清，页面保留适当留白，文字不要贴满四边。

## 四、叙事与汇报节奏

1. **开篇快速切入。**不要冗长铺垫，尽快说明研究意义与核心难题，让评委快速抓住研究目标。
2. **合理分配时间。**把最多时间分配给“���作 + 结果”，背景与意义不宜占时过长。硕士答辩常规陈述为 10–15 分钟时，背景和意义控制在 2–3 分钟左右。
3. **按逻辑讲解结果。**不只是报数字，还要讲清楚：这组实验要解决哪个难题、对比基准是什么、结果带来了什么改善。
4. **结尾回扣闭环。**结论要回到开头的意义与难题，说明本研究在多大程度上解决了提出的问题，并交代局限与展望；不要只复述做过哪些实验。
5. **客观说明局限与展望。**主动说明真实研究边界，不回避不足；展望应承接本工作的延伸方向，避免空泛表述。

## 五、备份页建议

单独准备一套备份幻灯片，存放次要实验、补充推导、消融实验和对比细节。正式汇报时不展示；评委追问细节时再切换作答，保证主 PPT 主线干净、叙事连贯。

## 六、高频踩坑

1. **逻辑断裂：**意义、难题、工作、结果彼此独立，没有一一对应，缺少闭环。
2. **PPT 变成论文截图：**大段复制正文，页面标题只是章节名称，缺少观点提炼。
3. **文献综述堆砌：**引用过多，迟迟没有引出自己要解决的真实难题。
4. **只罗列实验结果：**不解读结果，也不说明结果解决了什么问题。
5. **创新点空泛：**没有和前面提出的领域难题建立对应关系。
6. **结尾没有回扣：**只总结做过哪些工作，没有回到开篇的研究意义与待解决难题，导致闭环失效。
